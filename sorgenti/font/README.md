# font

- `Outfit-Black.ttf`: Outfit Black statico, scaricato da Google Fonts / [Outfitio](https://github.com/Outfitio/Outfit-Fonts). Licenza SIL Open Font License 1.1, testo in `OFL.txt`.

Serve solo allo script `npm run genera-nome-3d`, che estrae i contorni delle lettere di nome e cognome in `public/nome/outfit-black-nome.json` per il nome in metallo 3d. Il sito non scarica questo file: il testo usa Outfit Variable da `@fontsource-variable/outfit`; ChicagoFLF (schermo del computer) sta in `src/assets/font/`.
